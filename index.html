חיבור שמירה בענן לכל החברים

חינמי לגמרי • כל תמונה שתעלו תישמר ותופיע אצל כולם

כרגע האתר מחובר לענן הזמני של חלון התצוגה. כדי שהשמירה האוטומטית תעבוד גם אחרי שתעלו את האתר לכתובת משלכם באינטרנט, חברו פרויקט חינמי של Google Firebase לפי 4 השלבים למטה:

הגדרה חד-פעמית (2 דקות, חינם ללא כרטיס אשראי):

  1. היכנסו ל-console.firebase.google.com ולחצו Add project (תנו שם כמו haramaton).
  2. בתפריט השמאלי: Build ← Firestore Database ← לחצו Create database ← בחרו Start in test mode ← Create.
  3. בתפריט השמאלי: Build ← Authentication ← לחצו Get started ← הפעילו את Anonymous ולחצו Save.
  4. לחצו על גלגל השיניים למעלה ← Project settings ← למטה תחת Your apps לחצו על אייקון </> (Web), תנו שם והעתיקו את כל הקוד שמופיע (כולל const firebaseConfig = ...).

השמירה האוטומטית בענן מחוברת ופעילה!
